# BMI Tracker

## About the Project

BMI Tracker is a simple Python project that calculates a person's Body Mass Index (BMI) using their height and weight.

The program takes the user's name, height in meters, and weight in kilograms as input. It then calculates the BMI and shows the BMI category along with a simple suggestion.

## Features

- Takes user's name as input
- Takes height and weight from the user
- Calculates BMI
- Shows BMI value
- Shows BMI category
- Gives a simple health-related suggestion
- Easy to understand for beginners

## Formula Used

BMI = Weight / (Height × Height)

Where:
- Weight is in kilograms
- Height is in meters

## Technologies Used

- Python

## Python Concepts Used

- Variables
- Input and Output

- Basic Python Programming

## How to Run

1. Download or clone this repository.
2. Open the Python file.
3. Run `BMI TRACKER.py`.
4. Enter your name, height and weight when asked.
5. The program will display your BMI and category.

## Example

```text
===FITNESS & BMI TRACKER===

enter your name: Rahul
enter your height in meters: 1.7
enter your weight in kg: 65

---result---
name: Rahul
BMI: 22.49
category: normal range
suggestion: maintain a balanced diet and regular activity
```
