# Project Statement

My project is a **BMI Tracker** made using Python. The main purpose of this project is to calculate the BMI of a person using their height and weight.

In this project, the user enters their name, height in meters and weight in kilograms. The program uses the BMI formula to calculate the BMI value. After that, it checks the BMI value using if-elif-else conditions and displays the related category and a simple suggestion.

I made this project to improve my understanding of basic Python concepts such as variables, input and output, type conversion, arithmetic operators and conditional statements. This project is simple, but it helped me understand how these concepts can be used together to make a working program.
